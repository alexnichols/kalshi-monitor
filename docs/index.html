About the data

A GitHub Actions job runs kalshi_pipeline.py every night and commits data.json next to this page, which loads it automatically. Until that file exists, or where it can’t be reached, the page falls back to the built-in snapshot. Load data file still works for a one-off file.

  • Pipeline file (primary): every Kalshi fill from the public trades endpoints, categorized by Kalshi’s series metadata, and priced with Kalshi’s fee schedule using each series’ and event’s fee terms in force on the trade date. Perps from the Kalshi and Hyperliquid APIs.
  • Built-in snapshot (until the pipeline runs): Kalshi category volume from TickerTracker, which compiles Kalshi’s published daily market data; venue and perps volumes from DeFi Rate. The snapshot has no fees: fees appear only once trade-level data is loaded.
  • Polymarket volumes still come from DeFi Rate’s venue data; the pipeline does not pull Polymarket yet.
  • Partial periods: category volumes for November 2026 cover Nov 1 to 12; venue and perps figures run through Nov 13.
